## 0.1.2

* All the `kommonlee-*` projects are now in one sbt multi-module repo, with their Git history.
* The new groupId is `io.kevinlee` (it was `org.elixirian`). The package names are the same.
* All the modules have one shared version.
* ASM 5.0.3 is shaded into `kommonlee-asm` as `org.elixirian.kommonlee.lib3rd.asm5`, so `kommonlee-3rd-asm` is no longer necessary.
* The license changed from Apache 2.0 to MIT.
* Java 8 or later is necessary.
